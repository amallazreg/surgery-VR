# Module 11 — Prise en Main du Casque VR
Niveau : Tous niveaux (obligatoire avant tout autre module)
Type : Utilisation VR

---

## 1. Description générale
Ce module transversal est obligatoire pour tous les nouveaux utilisateurs
de SurgeryVR. Il enseigne comment utiliser le casque VR, les controllers,
et naviguer dans l'interface de la plateforme. Aucune connaissance
chirurgicale n'est requise pour ce module.

---

## 2. Étapes du module

Étape 1 — Mise en place du casque
  Régler l'écartement interpupillaire (IPD).
  Ajuster le bandeau pour un confort optimal.
  Vérifier la netteté de l'image (mise au point).
  Temps recommandé : 5 minutes maximum.

Étape 2 — Calibration des controllers
  Tenir les deux controllers correctement (comme des instruments chirurgicaux).
  Calibration de la position des mains dans l'espace VR.
  Test des gâchettes, joysticks et boutons.

Étape 3 — Navigation dans le menu SurgeryVR
  Ouvrir le menu principal avec le bouton Menu.
  Naviguer entre les modules avec le joystick gauche.
  Sélectionner un module avec la gâchette droite.
  Accéder aux paramètres et au profil utilisateur.

Étape 4 — Comprendre l'interface VR
  Tableau de bord de score en temps réel (haut gauche).
  Indicateur de progression du module (haut droite).
  Guide contextuel (bas centre, apparaît automatiquement).
  Chronomètre de session (haut centre).

Étape 5 — Exercice de base : manipulation d'objets
  Saisir un objet virtuel avec la gâchette.
  Le déplacer et le poser avec précision.
  Passer un objet d'une main à l'autre.
  Évaluation : précision et fluidité des mouvements.

Étape 6 — Gestion de l'inconfort VR (si nécessaire)
  Reconnaître les signes de cybercinétose (nausée légère).
  Utiliser la pause avec le bouton B.
  Régler la zone de confort (vignettage activable).
  Recommandation : sessions de 20-30 minutes max au début.

---

## 3. Matériel VR utilisé

- Casque VR compatible SurgeryVR (Meta Quest 3 / HTC Vive Pro)
- Controllers gauche et droit
- Station de base (pour tracking room-scale si applicable)
- Câble Link ou connexion Wi-Fi (selon configuration)

---

## 4. Référence des boutons controllers

### Controller Gauche
- Joystick gauche    : déplacement / déplacer la caméra
- Bouton X           : action contextuelle 1
- Bouton Y           : action contextuelle 2 / aide anatomique
- Gâchette gauche    : saisir / instrument gauche
- Bouton grip gauche : tenir un objet lourd
- Bouton Menu        : ouvrir le menu principal

### Controller Droit
- Joystick droit     : zoom / rotation de vue
- Bouton A           : changer d'instrument
- Bouton B           : pause / menu du module
- Gâchette droite    : activer l'instrument / saisir
- Bouton grip droit  : tenir / stabiliser

## 5. Problèmes fréquents et solutions

Problème 1 : Image floue
  → Régler l'IPD (écartement pupillaire) sur le côté du casque
  → Nettoyer les lentilles avec le chiffon fourni

Problème 2 : Controllers non détectés
  → Vérifier les piles des controllers
  → Rester dans la zone de tracking (zone délimitée au sol)
  → Redémarrer le casque (appui long sur bouton power)

Problème 3 : Nausée / malaise
  → Faire une pause immédiate (Bouton B)
  → S'asseoir et retirer le casque
  → Attendre 15 minutes avant de reprendre
  → Activer le mode vignettage dans les paramètres

Problème 4 : Lag ou saccades
  → Vérifier la connexion Wi-Fi (signal fort requis)
  → Fermer les applications en arrière-plan
  → Réduire la qualité graphique dans les paramètres

Problème 5 : Position des mains incorrecte dans la VR
  → Recalibrer les controllers (Menu > Paramètres > Calibration)
  → Vérifier qu'il n'y a pas d'objets obstruant le tracking

Problème 6 : Batterie faible
  → Charger le casque entre chaque session
  → Autonomie : environ 2-3 heures par charge

---

## 6. Conseils pour une bonne expérience VR

- Toujours faire le Module 11 avant le premier module chirurgical
- Commencer par des sessions courtes (15-20 min)
- Utiliser le casque dans une pièce bien dégagée (2m x 2m minimum)
- Ne pas utiliser le casque si vous portez des lunettes sans adaptateur
- Faire des pauses régulières toutes les 30 minutes
